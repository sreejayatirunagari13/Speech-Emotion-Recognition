# **Speech Emotion Recognition using Deep Learning**

📘 Overview

This project aims to identify human emotions from speech signals using deep learning techniques. It was developed as part of the Smart India Hackathon Problem Statement, focusing on improving human-computer interaction through emotion-aware systems.

The system classifies emotions such as happy, sad, angry, neutral, etc., based on audio features extracted from speech samples.

🚀 Features

+ Detects emotions from speech input
+ Uses MFCC (Mel-Frequency Cepstral Coefficients) for feature extraction
+ Built using Deep Learning models (CNN + RNN/LSTM)
+ Supports multi-class emotion classification
+ Achieved high testing accuracy on benchmark datasets

🧠 Tech Stack
+ Language: Python
+ Libraries: TensorFlow / Keras, Librosa, NumPy, Pandas, Matplotlib, Scikit-learn
+ Dataset: Toronto Emotional Speech Set(TESS) / Custom dataset (as applicable)
+ Environment: Google Colab

🧩 System Architecture
+ Audio Input – Speech samples collected from datasets
+ Feature Extraction – MFCC and chroma features computed using Librosa
+ Model Training – CNN + RNN architecture trained for emotion classification
+ Testing & Evaluation – Model validated using accuracy, confusion matrix, and F1 score

👩‍💻 My Role
+ Conducted testing and evaluation of the trained deep learning models.
+ Measured accuracy, precision, recall, and F1 score on test datasets.
+ Performed error analysis to identify misclassified emotions.
+ Suggested model improvements for better generalization and noise resistance.

📈 Results
+ Achieved 80% accuracy on test data.
+ Model successfully recognized core emotions with high reliability.
+ Demonstrated potential for integration into AI assistants, call analytics, and mental health monitoring systems.
